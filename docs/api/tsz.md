# tSZ Likelihoods (GODMAX)

These classes implement Gaussian likelihoods for the thermal Sunyaev-Zel'dovich (Compton-y) auto-spectrum and its crosses with the Euclid photometric probes, computed with the GODMAX halo model of cloelib. They run in decoupled mode only.
